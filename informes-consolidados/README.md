# Informes consolidados de cartera (en desarrollo)

Herramienta para armar el informe trimestral consolidado de un cliente con varias cuentas:

- Lee los exports de movimientos de InvBroker, las posiciones iniciales del año y una planilla de precios.
- Calcula las posiciones por cuenta y las consolidadas con **precio promedio ponderado**.
- Obtiene el costo, la valuación, el rendimiento, la ponderación y las operaciones del año con su resultado.

Falta: la salida en Excel y PDF, que se va a ajustar al formato del consolidado actual.

**No subir datos reales de clientes a este repositorio.**
